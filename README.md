The Train Ticket Reservation System is a web-based application developed using React.js that allows users to search trains, view train details, book train tickets, and manage booking history through an easy-to-use interface.
This project simulates an online railway reservation platform where users can search available trains between stations, view schedules and fares, reserve tickets, edit booking information, and cancel reservations.

Features
 > Attractive Home Page
 > Train Listing Page
 > Search Trains by Source and Destination
 > View Train Details
 > Book Train Tickets
 > Edit Booking Information
 > Cancel Tickets
 > Booking History Management
 > Dashboard with Booking Statistics
 > Responsive User Interface

Technologies Used
> React.js
> JavaScript (ES6)
> HTML5
> CSS3
> React Router DOM
